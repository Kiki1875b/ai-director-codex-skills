# 작법 원칙

이론서(맥키 『STORY』, 스나이더 『Save the Cat』, 시드 필드, 시퀀스 접근법)를 점검 가능한 규칙으로 줄인 것이다. 원문 인용이 아니라 요약이다.

## 1. 이야기의 척추

- **극적 질문 하나**: "주인공은 X를 얻을 것인가?" 관객이 끝까지 이 질문을 들고 간다. 결말이 이 질문에 답한다(예/아니오/예지만 대가).
- **주인공**
  - 원하는 것(want, 외적 목표): 화면으로 보여줄 수 있어야 한다
  - 필요한 것(need, 내적 변화): 대개 원하는 것과 충돌한다
  - 결함과 상처: 왜 지금 이 사람이 이 문제에 약한지
  - 능동성: 사건이 주인공에게 일어나는 것보다 주인공의 선택이 사건을 만든다
- **적대 세력**: 주인공보다 강해야 갈등이 산다. 사람, 자연, 제도, 자기 자신 중 하나를 분명히 한다.
- **대가(stakes)**: 실패하면 무엇을 잃는지 1막 안에 보여준다. 시간 제한(ticking clock)은 짧은 길이에서 특히 효과가 크다.

## 2. 구조

### 장면 단위 (모든 길이 공통)
- 장면마다 **목표 → 갈등 → 결과**가 있다.
- 장면 끝에 **가치가 바뀐다**: 안전→위험, 신뢰→의심, 희망→절망. 바뀌지 않는 장면은 자르거나 합친다.
- 늦게 들어가서 일찍 나온다. 인사·이동·설명으로 시작하지 않는다.
- 장면 안에서 정보는 행동과 소품으로 준다. 같은 정보를 두 번 주지 않는다.

### 길이별 템플릿

**숏폼 180초 이하 (1막 압축형)**

| 구간 | 비율 | 내용 |
|---|---|---|
| 훅 | 0~5% (첫 3~5초) | 이상함 또는 위기를 이미 진행 중인 상태로 보여준다 |
| 설정 | ~20% | 원하는 것과 규칙(세계의 룰, 시간 제한) |
| 전환 1 | ~25% | 되돌릴 수 없는 선택 |
| 상승 | 25~75% | 시도 → 실패 → 더 큰 시도. 같은 규칙 안에서 수위만 올린다 |
| 반전/위기 | ~75% | 가장 큰 손실 또는 숨겨진 사실 공개 |
| 보상 | 마지막 10~15% | 극적 질문에 대한 답. 도입에서 심은 것을 회수한다 |

장면은 3~6개, 컷은 10~25개가 적당하다.

**단편 180초 초과 ~ 20분 (시퀀스형)**
- 3막을 시퀀스로 나눈다: 3~5분은 3개, 5~10분은 4개, 10~20분은 5~6개. 시퀀스마다 작은 목표와 작은 결과가 있다.
- 비트와 위치(전체 길이 대비 비율). 짧을수록 비트를 합친다(3~5분은 굵은 글씨 비트만).

| 비트 | 위치 | 내용 |
|---|---|---|
| **오프닝 이미지** | 0~2% | 변하기 전의 세계를 한 이미지로 |
| 주제 제시 | ~5% | 누군가 주제를 스치듯 말하거나 보여줌 |
| **촉발 사건** | ~10% | 일상을 깨는 사건 |
| 망설임 | 10~20% | 갈지 말지, 대가 확인 |
| **2막 진입** | ~25% | 되돌릴 수 없는 선택 |
| 재미와 게임 | 25~50% | 장르의 약속을 가장 많이 보여주는 구간 |
| **중간점** | ~50% | 가짜 승리 또는 가짜 패배, 판돈 상승 |
| 다가오는 악당 | 50~75% | 안팎의 압박이 조여 옴 |
| **모든 것을 잃음** | ~75% | 가장 큰 손실 |
| 영혼의 어두운 밤 | 75~80% | 바닥에서의 깨달음 |
| 3막 진입 | ~80% | 새 방법으로 다시 도전 |
| **피날레** | 80~98% | 극적 질문의 답 |
| **클로징 이미지** | 98~100% | 오프닝 이미지와 대비 |
- 오프닝 이미지와 클로징 이미지는 서로 대비된다(변화의 증거).
- 중간점에서 극적 질문의 판돈이 올라간다.

## 3. 인물

- 인물마다 한 줄: `이름 — 원하는 것 / 두려워하는 것 / 말버릇이나 행동 습관 하나`.
- 인물을 처음 등장시킬 때 그 사람의 본질을 보여주는 행동 하나로 소개한다(외모 나열 금지).
- 조연은 주인공의 다른 선택지를 보여준다(거울, 유혹, 경고).
- 숏폼은 주요 인물 3명 이하. 이름은 부르기 쉽고 서로 첫 글자가 다르게.

## 4. 대사

- 인물은 원하는 것을 직접 말하지 않는다. 말과 행동이 어긋날 때 서브텍스트가 생긴다.
- 정보 전달용 대사("너도 알다시피…")를 쓰지 않는다. 필요한 정보는 갈등 속에서 드러낸다.
- 대사 한 줄은 숏폼에서 2~3초(약 10~15자) 안에 끝난다. 긴 말은 컷을 나눈다.
- 인물마다 어휘와 리듬을 다르게 한다. 이름을 가려도 누구 대사인지 알 수 있어야 한다.
- 침묵과 리액션 컷도 대사다.

## 5. 장르와 클리셰

- 장르는 관객과의 약속이다. 약속한 경험(공포, 설렘, 통쾌함)을 반드시 준다.
- 장르의 필수 장면은 넣되, 클리셰 하나를 골라 **한 번 비튼다**(genres.md 참고).
- 반전은 앞에서 공정하게 심은 단서로만 만든다. 다시 보면 보이는 단서 2개 이상.

## 6. 주제

- 주제는 대사로 말하지 않는다. 주인공의 마지막 선택으로 증명한다.
- 한 문장: "X는 Y할 때 Z한다"(예: "외로움은 대가를 치를 때 끝난다").

## 7. AI 영상 제작 제약 (시나리오 단계에서 지킬 것)

- 컷 하나에 주요 행동 하나. 컷 길이 3~10초.
- 주요 인물 3명 이하, 장소는 숏폼 1~3곳·단편 6곳 이하. 같은 장소를 재사용한다.
- 피할 것과 대안:
  - 군중, 전투 대규모 → 실루엣, 소리, 결과 인서트
  - 정밀한 손동작, 악기 연주, 글씨 쓰기 → 결과 인서트나 클로즈업 리액션
  - 화면 속 읽어야 하는 글자 → 자막
  - 여러 명이 동시에 말함 → 컷을 나누고 음성은 후시
  - 복잡한 변신 → 전후 상태 2컷 + 효과음, 또는 그림자·빛 처리
- 의상 변경은 바이블의 변형 엔트리로만(`ch_x@outfit`). 장면 중간에 갑자기 옷이 바뀌지 않는다.
- 시간·날씨·조명은 씬 단위로 고정하고 씬 헤딩에 적는다.
