# 장르 플레이북

장르마다: 관객에게 하는 약속 / 필수 장면 / 흔한 클리셰 → 비틀기 예 / AI 영상 적합도. 고른 장르 항목만 읽는다. 톤 레퍼런스 작품은 분위기 설명용이며 줄거리를 빌리지 않는다.

**비틀기 예시는 원리를 보여주는 것이다. 문장을 그대로 쓰지 말고, 같은 원리로 이번 이야기에 맞는 새 비틀기를 만든다.** 예시를 그대로 쓰면 그것이 새 클리셰가 된다.

## 오컬트·민속 판타지 (구미호, 도깨비, 무속, 저승)
- **약속**: 이 세계에는 보이지 않는 규칙이 있고, 그 규칙을 어기면 대가를 치른다.
- **필수**: 규칙(금기)의 제시 → 금기 위반 → 대가의 도래 → 의식이나 거래로 해결 시도 → 대가의 지불.
- **클리셰 → 비틀기**: 요괴는 인간을 해친다 → 요괴가 인간의 규칙에 묶여 손해를 본다 / 퇴마사가 이긴다 → 퇴마의 대가가 이겨도 남는다.
- **AI 적합도**: 높음. 안개, 달빛, 실루엣, 정적인 긴장으로 연출이 쉽다. 변신은 2컷+그림자로.

## 판타지 로맨스
- **약속**: 넘을 수 없는 경계를 사이에 둔 두 사람이 서로를 선택하는 순간.
- **필수**: 만남(어긋난 첫인상) → 경계의 정체(종족, 계약, 시간) → 가까워짐 → 경계가 대가를 요구 → 선택.
- **클리셰 → 비틀기**: 인간이 되려고 모든 것을 버린다 → 상대가 대신 경계를 넘는다 / 기억을 잃는다 → 기억은 남고 다른 것을 잃는다.
- **AI 적합도**: 높음. 2인, 적은 장소, 클로즈업 중심.

## 스릴러·서스펜스
- **약속**: 관객이 인물보다 조금 더 알고, 그래서 조마조마하다.
- **필수**: 위협의 존재 공개 → 시간 제한 → 탈출/추적 시도 실패 → 정체 반전 → 대면.
- **클리셰 → 비틀기**: 범인은 가장 의외의 인물 → 범인은 처음부터 보였지만 동기가 의외 / 전화가 끊긴다 → 연결은 되는데 상대가 이미 알고 있다.
- **AI 적합도**: 중간. 추격은 짧은 컷과 소리로 처리한다.

## 호러
- **약속**: 안전한 공간이 무너지고, 보이지 않는 것이 가장 무섭다.
- **필수**: 평범한 일상 → 작은 이상 징후 3회(점점 커짐) → 확인하러 감 → 가짜 안도 → 진짜 공포 → 열린 결말 또는 대가.
- **클리셰 → 비틀기**: 점프 스케어 → 기다렸는데 안 나오고, 다음 컷 배경에 이미 있다 / 혼자 확인하러 간다 → 이유가 납득되는 상황(아이, 반려동물).
- **AI 적합도**: 높음. 어둠과 프레임 가장자리가 생성 결함을 가려 준다.

## 미스터리
- **약속**: 관객도 함께 풀 수 있는 공정한 퍼즐.
- **필수**: 사건 → 단서 3개(하나는 가짜) → 잘못된 결론 → 놓친 단서 재발견 → 해답과 동기.
- **클리셰 → 비틀기**: 탐정의 장황한 해설 → 해설 없이 회상 인서트 3컷으로 / 범인 자백 → 증거 소품 하나로 침묵 속 확정.
- **AI 적합도**: 중간. 단서 소품은 바이블 오브젝트로 고정해야 한다.

## 드라마·휴먼
- **약속**: 인물이 변하고, 관객이 그 변화를 함께 느낀다.
- **필수**: 결핍 → 관계의 시작 → 충돌 → 상실 또는 위기 → 화해·수용의 작은 행동.
- **클리셰 → 비틀기**: 눈물의 고백 → 말 대신 행동 하나(우산을 건넨다) / 병 진단 반전 → 이미 알고 있던 쪽이 숨기고 있었다.
- **AI 적합도**: 높음. 감정 연기는 클로즈업 리액션 중심으로, 대사를 줄인다.

## 코미디 (상황극)
- **약속**: 인물이 진지할수록 상황이 웃기다.
- **필수**: 정상인의 목표 → 이상한 규칙 또는 인물 → 해결 시도마다 악화 → 최악의 순간 → 예상 밖 해결.
- **클리셰 → 비틀기**: 넘어지는 몸개그 → 넘어질 듯 안 넘어지고 다른 사람이 넘어진다.
- **AI 적합도**: 높음. 병맛·브레인롯 숏폼이면 `ai-video-fun-writer`로 넘긴다.

## SF
- **약속**: 하나의 기술(설정)이 인간관계를 바꾼다.
- **필수**: 설정 제시(규칙 1개) → 일상 속 이점 → 부작용 → 설정의 극단 → 인간적 선택.
- **클리셰 → 비틀기**: AI가 반란한다 → AI가 너무 순종해서 문제가 된다.
- **AI 적합도**: 중간~높음. 세트·소품을 바이블로 고정한다. 화면 UI 글자는 피한다.

## 액션
- **약속**: 목표가 분명한 물리적 대결과 쾌감.
- **필수**: 목표와 장애물 → 첫 충돌 패배 → 준비·전략 → 클라이맥스 대결 → 대가 있는 승리.
- **클리셰 → 비틀기**: 1 대 다수 난투 → 좁은 공간 1 대 1, 환경을 무기로.
- **AI 적합도**: 낮음~중간. 합이 긴 격투는 불가. 결정적 순간 3~4컷(준비, 충돌, 결과)으로 압축한다.

## 사극·시대극
- **약속**: 신분과 시대의 규칙이 인물의 선택을 짓누른다.
- **필수**: 신분의 벽 → 규칙을 어길 이유 → 발각 위기 → 대가 → 선택의 의미.
- **클리셰 → 비틀기**: 신분 상승 해피엔딩 → 벽은 그대로, 작은 자유를 얻는다.
- **AI 적합도**: 중간. 의상·건축 고증은 바이블 앵커로 고정한다.

## 길이별 추천 조합
- 60~90초: 오컬트, 호러, 판타지 로맨스(한 장면 고백형), 코미디
- 3분 안팎: 스릴러, 미스터리(단서 2개), 드라마
- 5~20분: 모든 장르. 액션·SF는 장소와 인물 수를 먼저 제한한다.
