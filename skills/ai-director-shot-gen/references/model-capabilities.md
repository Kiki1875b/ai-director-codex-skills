공통:
- 81프레임(5초)을 넘기면 반복·드리프트. 7초 이상은 쓰지 않는다(이 모델 기준).
- 먼 인물(얼굴 폭 30px 미만)은 어느 방식이든 얼굴이 무너진다. 얼굴 디테일러로도 한계가 있다.
- 비는 프롬프트로 거의 안 나온다. 키에 빗줄기가 있으면 영상에서 움직인다(S5-3). 없으면 편집에서 합성한다.
- **정지 카메라는 프롬프트로 지켜지지 않는다**(2026-11-08 S1, 시작 1장 6건 모두). "Locked-off, tripod, never moves"와 NAG 부정어(camera movement, dolly, zoom)를 넣어도 카메라가 옆으로 흐르거나(S1-1 14px, S1-5 49px) 푸시인(S1-2 v7·v8 인물 1.4배, S1-3 +9%)했다. 이 클립들은 0.5초 간격 접촉 시트로는 고정처럼 보였다. 검수에서는 첫·끝 프레임을 원본 크기로 겹쳐 본다. 움직일 것이 비뿐인 와이드는 키 + 비 합성(`<skills>/ai-director-shot-gen/scripts/still_rain.py KEY.png OUT.mp4 --dur 5`)이 확실하다. 작은 흐름(약 15px 이하)은 안정화하고 크롭한다.
- **끝 키를 넣으면 카메라가 고정된다**(S1-5 v5: 시작 1장 v4는 49px 흐름 + 제자리 걸음 → 첫·끝 키 v5는 흐름 0, 발 교대 정상). 끝 키는 시작 키에서 바뀌는 부분만 한 번 편집하고, 나머지 픽셀은 시작 키로 되돌린다. 그래서 배경이 같은 두 장이 카메라를 붙잡는다. 같은 이미지를 처음과 끝에 넣으면 안 된다(S2-4 v5 줌 왕복). 끝 4프레임쯤에서 밝기가 끝 키로 끌려가니 마지막 6프레임은 자르거나 맞춘다. 끝 키의 작은 변화는 과장된다: 코트 자락 몇 cm → 치마처럼 48px 들림(S1-1 v6). 고개 기울임처럼 몸이 스스로 하는 동작에 쓰고, 천의 흔들림은 넣지 않는다. 키에 없던 비는 첫·끝 키에서도 생기지 않는다(S1-2 v11) → 비 층을 합성한다.
- 작은 광원(구슬 속 불꽃)은 영상에서 색이 바뀌고 환영이 구슬 전체로 번진다(S1-4 v3). 불꽃을 지운 키로 생성하고 편집에서 합성한다(`edit/s14_bead_composite.py`).
- 서버 작업 ID(`prompt_id`)는 version `job_id`에 남긴다. 받는 중 연결이 끊기면 `--fetch <job_id>`로 다시 받는다(S5-3 vace1).
