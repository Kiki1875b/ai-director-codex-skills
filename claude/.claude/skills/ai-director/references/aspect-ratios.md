# 화면비 (작품 설계 첫 단계에서 사용자가 고른다)

화면비는 기본값으로 채우지 않는다. 작품을 새로 설계할 때 **9:16 / 16:9 / 2.39:1** 중 하나를 사용자에게 묻고, 정한 값을 아래 표대로 모든 단계에 적용한다. 작품 중간에 바꾸면 키·영상을 다시 만들어야 하므로 바꾸기 전에 비용을 알린다.

| | 9:16 세로 | 16:9 가로 | 2.39:1 시네마스코프 |
|---|---|---|---|
| 어울리는 곳 | 쇼츠·릴스·틱톡, 휴대폰 시청 | 유튜브 가로, 일반 영상 | 영화 느낌, 넓은 풍경·인물 사이 거리 |
| `story.format.aspect_ratio` | `"9:16"` | `"16:9"` | `"2.39:1"` |
| `export` | 1080×1920, `fit: "pad"` | 1920×1080, `fit: "pad"` | **1920×804, `fit: "crop"`** |
| 키 프롬프트 1줄 | `Portrait 9:16 single film frame.` | `Landscape 16:9 single film frame.` | `Landscape 16:9 single film frame composed for a 2.39:1 widescreen crop: heads, eyes, hands and key props stay inside the central horizontal band (middle 74% of the height); top and bottom 13% hold only sky, ceiling, floor or wall.` |
| LTX (`ltx_remote.py`) | `--width 704 --height 1280` | 기본값 1280×704 | 1280×704로 생성하고 편집에서 2.39로 자름 |
| Wan (`wan_remote.py`) | `--width 720 --height 1280` | 기본값 1280×720 | 1280×720로 생성하고 편집에서 자름 |
| 키 검수 크기 | 휴대폰 크기 | 화면 크기 | **2.39로 자른 그림**을 화면 크기로(아래) |
| 콘티 시트 | 9:16 칸 | 16:9 칸 | 2.39:1 칸 (`build_sheet_prompt.py`가 aspect_ratio를 읽음) |

## 2.39:1 방법
- 이미지·영상 모델은 2.39 비율을 직접 만들지 않으므로 **16:9로 만들고 가운데 띠(높이의 74%)를 쓴다.** 1280×704 → 1280×536, 최종 1920×804. 렌더(`render_timeline.py`)가 `export.fit: "crop"`이면 가운데 기준으로 자른다.
- 키 검수 전에 자른 그림을 만들어 본다: 위아래 각 13%를 잘라낸 이미지(PIL)로 keyframe-reviewer에 준다. 잘린 띠에 머리·손·소품이 걸리면 REVISE다.
- 카메라가 위아래로 움직이는 컷(틸트, 크레인)은 잘린 띠 밖으로 피사체가 나가기 쉽다. 설계 단계에서 피한다.
- 화면 위아래에 검은 띠를 넣은 16:9 파일이 필요하면(일부 플랫폼) 2.39 렌더를 받은 뒤 사용자 요청 시 따로 만든다.
- 미확인: LTX를 2.39에 가까운 비율(예: 1536×640)로 직접 생성하는 방법은 아직 시험하지 않았다. 시험 전까지 위의 자르기 방식을 쓴다.

## 비율별 연출 차이 (촬영 설계에 반영)
- **9:16**: 인물 한 명이 세로를 채우는 구도가 기본이다. 두 인물을 나란히 놓기 어려우므로 앞뒤 깊이(전경·후경)로 배치한다. 자막·UI가 위아래를 덮는 플랫폼은 위 10%, 아래 20%에 중요한 것을 두지 않는다.
- **16:9**: 두 인물 투샷, 어깨 너머 샷이 자연스럽다.
- **2.39:1**: 가로 여백이 커서 인물 사이 거리, 고립, 풍경을 보여 주기 좋다. 클로즈업은 얼굴 옆 공간이 넓게 남으므로 시선 방향 쪽에 여백을 둔다. 세로 동작(앉기·일어서기)은 머리가 잘리기 쉽다.

## 아직 16:9 전용인 도구
`face_detail.py`(1280×720 고정), `refine_remote.py`·`infinitetalk_remote.py` 기본 크기. 다른 비율에서 쓰려면 크기를 직접 넘기거나 도구를 고친 뒤 쓴다.
