# 한국 시나리오 표기법

## 요소

| 요소 | 표기 | 규칙 |
|---|---|---|
| 씬 번호와 헤딩 | `S#1. 폐사찰 법당 (밤)` | 장소와 시간(낮/밤/새벽/저녁). 실내외가 헷갈리면 `내부`/`외부`를 붙인다 |
| 지문 | 4칸 들여쓰기, 현재형 (대사와 구별되게) | 보이는 것과 들리는 것만. 한 단락 3줄 이내. 인물 첫 등장 시 이름 뒤 괄호에 나이 |
| 대사 | `이름: 대사` | 한 줄에 한 호흡 |
| 지시 | `이름: (작게) 대사` | 괄호 지시는 꼭 필요할 때만. 감정 지시 남발 금지 |
| 화면 밖 소리 | `이름(V.O.)`, `이름(O.S.)` | 내레이션은 V.O., 화면 밖 인물은 O.S. |
| 인서트·회상 | `(인서트) 붉은 노리개`, `(회상)` / `(현재)` | 짧게 |
| 전환 | `컷 투.`, `디졸브.` | 의미 있는 전환에만 쓴다 |
| 음향 | `— 풍경 소리.` | 중요한 소리는 지문에 따로 한 줄 |

숏폼 컷 대본이 필요하면 표 형식(시간 | 화면·행동 | 대사 | 소리 | 가치)을 추가로 붙인다.

## 짧은 예시 (자작, 형식 참고용)

```
S#1. 폐사찰 법당 (밤)

    무너진 지붕 틈으로 달빛. 먼지 쌓인 불상 앞, 촛불 하나가 홀로 타고 있다.
    촛불 그림자가 벽에 비치는데, 그림자에만 꼬리가 아홉 개.

    — 풍경 소리. 바람은 없다.

    문간에 서연(20대 후반, 우산을 접어 든 등산복 차림)이 멈춰 선다.
    서연, 촛불을 본다. 누군가 방금 켰다.

서연: 누구 계세요?

    대답 대신 촛불이 꺼진다.
    어둠 속에서 금빛 눈 두 개가 뜬다. 서연보다 높은 곳에서.

구미호(O.S.): 비를 피하러 왔으면, 신발은 벗고 들어와야지.

    서연, 내려다본다. 자기 발. 젖은 등산화가 법당 마루에 발자국을 남겼다.
    (가치: 피난처 → 위협)
```

좋은 점: 정보(요괴의 정체)를 그림자 하나로 준다. 첫 대사가 위협이 아니라 예절이어서 서브텍스트(이곳의 규칙)가 생긴다. 장면 끝에 가치가 바뀐다.

같은 장면의 나쁜 예: `서연은 무서웠다. 구미호가 나타나 "나는 천 년 묵은 구미호다"라고 말했다.` — 감정을 지문에 직접 쓰고, 설명 대사로 정체를 밝혀 긴장이 사라진다.
